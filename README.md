# Completion Booster

这是一个为 VSCode snippets 添加数字标注的插件，可以通过数字快速选择你想要的 snippet。

## 特性

- 在 snippets 提示列表中为每个选项添加数字标注
- 可以通过数字键快速选择对应的 snippet
- 支持所有编程语言

## 使用方法

1. 安装插件后重启 VSCode
2. 在编辑器中触发 snippets 提示时，每个选项前会显示对应的数字
3. 直接输入数字即可选择对应的 snippet

## 配置项

在设置中可以找到以下配置：

- `completionBooster.enabled`: 是否启用 snippets 数字标注功能（默认：true）

## 注意事项

- 该插件会修改原有 snippets 的显示方式，但不会影响实际插入的代码内容
- 如果遇到任何问题，可以在设置中临时禁用该功能
